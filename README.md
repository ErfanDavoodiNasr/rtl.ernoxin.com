# نمایشگر فارسی ارنوکسین

نمایش راست‌چین متن فارسی با فونت‌های محلی، رندر فرمول KaTeX، هایلایت کد، جدول و Mermaid — بدون CDN و بدون وابستگی به API
خارجی.

## توسعه

```bash
npm install
npm run dev:safe
```

→ [http://localhost:3000](http://localhost:3000)

## دیپلوی روی cPanel

1. برو [Releases](https://github.com/ErfanDavoodiNasr/rtl.ernoxin.com/releases) و **`rtl.zip`** آخرین نسخه را دانلود کن
2. در cPanel → **File Manager** → `public_html` → zip را آپلود و **Extract** کن
3. `index.html` باید مستقیم داخل `public_html` باشد

برنامهٔ وب (اپلیکیشن) آفلاین اجرا می‌شود؛ فونت‌ها، KaTeX و اسکریپت‌ها داخل zip هستند. فایل HTML خروجی هم فونت وزیرمتن و
KaTeX را داخل خودش دارد و برای نمایش به اینترنت نیاز ندارد.

## خروجی

| فرمت     | رفتار                                                                |
|----------|----------------------------------------------------------------------|
| Markdown | نسخهٔ پردازش‌شده (همان چیزی که در پیش‌نمایش می‌بینید)                |
| HTML     | فایل **کاملاً آفلاین**؛ فونت وزیرمتن و KaTeX داخل خود فایل embed شده |
| PDF      | دانلود مستقیم فایل `.pdf` (JPEG فشرده؛ بدون تب blob/چاپ)             |
| PNG      | تصویر از کل پیش‌نمایش                                                |

خروجی HTML تنظیمات ظاهر فعلی (فونت، اندازه، فاصله خطوط) را هم اعمال می‌کند و به CDN وابسته نیست.

## میانبرها

| میانبر                 | عملکرد                             |
|------------------------|------------------------------------|
| `Ctrl/Cmd + Enter`     | جابه‌جایی بین پیش‌نمایش و دو پنجره |
| `Ctrl/Cmd + Shift + V` | جایگذاری از کلیپ‌بورد              |

## امنیت و حریم خصوصی

- سند فقط در مرورگر شما (localStorage / IndexedDB) می‌ماند؛ آنالیتیکس یا همگام‌سازی ابری وجود ندارد.
- HTML خام و خروجی HTML با sanitize دوباره فیلتر می‌شوند تا XSS و لینک‌های اجرایی دوباره زنده نشوند.
- تصاویر `https` داخل سند ممکن است درخواست شبکه بزنند؛ برای حریم خصوصی کامل از تصویر ریموت استفاده نکنید.
- بلوک‌های کدی که نویسه‌های جهت‌دار مشکوک (Trojan Source) دارند هشدار می‌گیرند؛ کپی همیشه متن اصلی را می‌دهد.
